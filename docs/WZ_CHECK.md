# Warunki zabudowy (WZ) — what the decision allows and how the model uses it

Source: Decyzja o warunkach zabudowy GN.6730.101.2024.MS, Wójt Gminy Narewka, 29.11.2024, działka 420 (obręb 19 Narewka).

| WZ item | Value | Status in the model |
|---|---|---|
| Scope | two detached residential buildings, ≤ 2 above-ground storeys | house = 1 building; second building not used (you said it will not be built) |
| Built area (powierzchnia zabudowy) | **≤ 70 m² each** | house 31.1 + extension 13.9 + kitchen bay 4.2 = **49.2 m²** → 20.8 m² still free |
| Floor area (kondygnacje nadziemne) | ≤ 120 m² each | ground ≈ 49 m² + loft ≈ 22 m² ≈ 71 m² |
| Height / roof | ≤ 8.0 m; gable, symmetric, 30–45°, usable attic allowed | ridge ≈ 4.7 m, 40° ✔ loft allowed ✔ |
| Front elevation | ≤ 10 m (+20 %) | 11.5 m long side — within the 12 m tolerance ✔ |
| Parking | 2–4 spaces | 2-car carport ✔ |
| Biologically active area | ≥ 500 m² | ≈ 1130 m² ✔ |
| Building line | ≥ 8.0 m from the road carriageway edge (ul. Mickiewicza); ≥ 6.0 m from the boundary of municipal road plot 469 | app flags structures within 6 m of the east boundary (assumed to be plot 469) |
| Rain water | on own unpaved ground, may not change flow towards neighbours | rain tanks + rain garden ✔ |
| Utilities | water + sewer connection (own well was requested), existing power connection, heat: boiler/heat pump/electric/stove | see verification list |

**Not covered by the WZ:** office, gym/sauna, bania, greenhouse, workshop, carport, boardwalk. The decision only covers residential buildings, so these need their own legal route (outbuilding rules / notification / permit) — to be clarified with the municipality or the designer.

**Kitchen bay.** The extension slab is already poured, so its footprint is untouched. The only new footprint is the 1.0 × 4.2 m bay at the south gable (half of the plan's loggia). The other half stays as a covered loggia deck along the big south window.
